# ELK Stack – Web Log Analytics Dashboard

## Project Overview
Built a web log analytics dashboard using Elasticsearch and Kibana to analyze and visualize sample web server logs.

## Tech Stack
- Elasticsearch
- Kibana
- ES|QL
- Elastic Cloud

## Key Features
- Loaded sample web server logs into Elasticsearch.
- Executed ES|QL queries for data analysis.
- Analyzed total web requests.
- Examined HTTP response status codes.
- Calculated average response size.
- Analyzed requests by file extension.
- Created an interactive Kibana dashboard.

## Dashboard Visualizations
1. Total Requests
2. HTTP Status Code Distribution
3. Average Response Size
4. Requests by File Extension

## Dataset
Kibana Sample Web Logs.

## Outcome
Demonstrated log analysis, Elasticsearch querying, data aggregation, and dashboard creation using Kibana.
